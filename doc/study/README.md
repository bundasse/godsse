# 학습 노트 (doc/study)

이 폴더는 `godsse` 프로젝트를 진행하며 만나는 **백엔드 · Java · Spring Boot · 컴퓨터공학** 내용을
학습용으로 정리해 두는 곳입니다. (대원칙 4번 — [../00-principles.md](../00-principles.md))

> 사용자 배경: Vue 프론트엔드 개발자, React 입문, 백엔드·Java·Spring·CS 초급.
> 모든 노트는 **프론트엔드(Vue/JS) 개념에 비유**하고, 용어는 `한국어(영어 원어)` + 한 줄 정의로 시작합니다.

## 작성 형식

각 노트는 아래 흐름을 따릅니다.

1. **개념** — 무엇인가 (한 줄 정의 → 조금 더 자세히)
2. **왜 필요한가** — 없으면 어떤 문제가 생기는가
3. **이 프로젝트에서는** — `godsse` 의 어느 파일/설정에서 쓰이는가 (경로 표기)
4. **예제 코드** — 실제 프로젝트 코드 인용
5. **확인 문제** — 스스로 점검 (선택)
